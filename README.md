# Проект неявной адаптации веб-каталога

Задание 3 по курсу «Проектирование и развертывание веб-решений в экосистеме Python».

LLM по истории обычного осмотра недвижимости выбирает три поля карточки и вид cards/comparison. Static всегда показывает цену, площадь и комнаты. Основной исход: покрытие трёх скрытых потребностей генератора; браузерные клики и техническое время оцениваются отдельно. Люди в эксперименте не участвуют.

[Отчёт](REPORT.md) содержит единое сравнение шести публикаций по 12 полям, исследовательский вопрос, гипотезы, архитектуру и девять уровней проверки. [Схема](architecture.mmd), [конфигурация](configs/experiment.json) и [протокол](configs/protocol.md) фиксируют проект до новых измерений.

План одного запуска: static/llm × focused/shift × 10 seeds, плюс пять static A/A-пар. Два свежих полных запуска используют те же входы и не объединяются статистически; при доступном API потребуется 20 HTTP-вызовов LLM на запуск. Модель и параметры закреплены в протоколе. Ошибки API остаются в оценке с DEFAULT.

Код и будущие результаты задания 4 находятся в отдельном репозитории [adaptive-ui-stand](../adaptive-ui-stand/). Проект не заявляет полученных измерений, обучения LLM или доказанной пользы для людей.
