# Проект стенда адаптивной навигации

Задание 3 по курсу «Проектирование и развертывание веб-решений в экосистеме Python».

Сравниваются фиксированные быстрые ссылки и два способа адаптации: по частоте и по давности обращений. Основная метрика: число кликов до нужной операции.

- [Схема стенда](architecture.mmd).
- [Конфигурация эксперимента](configs/experiment.json).
- [Протокол](configs/protocol.md), зафиксированный до измерений.
